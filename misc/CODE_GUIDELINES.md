# Code Guidelines

- As a general rule, follow the recommendations of the C++ Core Guidelines.
- Always brace conditional and loop bodies, even a single statement (MISRA C++ Rule 9.3.1).
- Always declare an explicit underlying type on enumerations (MISRA C++ Rule 10.2.1).
- Mark single-argument constructors and conversion operators as explicit (MISRA C++ Rule 15.1.3).
- Initialize variables at declaration (MISRA C++ Rule 11.6.1).
